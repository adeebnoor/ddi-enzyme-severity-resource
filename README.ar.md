# مجموعة بيانات لآليات التداخلات الدوائية مربوطة بالإنزيم المسؤول ودرجة الخطورة السريرية

> This is an Arabic summary. The full data descriptor is in
> **[README.md](README.md)** (English).

هذا المستودع هو السجل الكامل للبيانات الخاصة بالمخطوطة المقدَّمة إلى مجلة
*Scientific Data* بعنوان *"An enzyme-resolved dataset linking drug interaction
mechanisms to clinical severity grades"*.

## توفّر البيانات

جميع الملفات متاحة في هذا المستودع العام. **لا يوجد تسجيل ولا كلمة مرور ولا رسوم
ولا فترة حظر** — يستطيع أي شخص تنزيل كل شيء بشكل فوري ومجهول الهوية، إمّا من هذه
الصفحة أو عبر:

```bash
git clone https://github.com/adeebnoor/ddi-enzyme-severity-resource.git
```

الترخيص: **CC BY 4.0**.

## ما الذي تقدّمه هذه المجموعة

قواعد بيانات التداخلات الدوائية الميكانيكية تخبرنا **كيف** يتداخل دواءان، بينما
القواعد السريرية تخبرنا **ما مدى خطورة** التداخل. لم يكن هذان المصدران مربوطين
معاً من قبل.

هذه المجموعة توحّد مصدراً ميكانيكياً (GoldD3R المشتق من D3) مع مصدر سريري مصنَّف
حسب الخطورة (DDInter 2.0)، ثم — وهذه هي الخطوة الجوهرية — تُرجِع كل تداخل إلى
**الإنزيم أو الناقل الغشائي المسؤول عنه تحديداً**.

النتيجة: جدول على مستوى أزواج الأدوية تجتمع فيه الآلية والإنزيم المسؤول ودرجة
الخطورة السريرية في صف واحد، إضافة إلى إحصاءات لكل إنزيم وأربع عمليات تحقّق
خارجية مستقلة.

**بالأرقام:** ١٬٩٠٠ زوج دوائي موسوم بالإنزيم · ٢٤٠ دواء · ٣٥ إنزيماً وناقلاً ·
أربع عمليات تحقّق خارجية · متصفّح تفاعلي · كل شيء مفتوح.

## أبرز النتائج

- **CYP3A4 ليس مصدر الخطر المتوقَّع.** رغم أنه يتولّى أكبر عدد من التداخلات
  (٢٣٤ زوجاً)، فإنه **مُستنفَد** من التداخلات شديدة الخطورة
  (OR = 0.49، q = 0.017).
- **الإنزيمات المرتبطة فعلاً بالخطورة الشديدة** هي الناقل
  **SLCO1B1 (OATP1B1)** (OR = 5.24، q = 0.022) و**CYP2C9**
  (OR = 2.86، q = 0.001).
- **درجات الخطورة تصمد أمام التحقق الخارجي.** الأزواج المصنَّفة تتأكّد في
  قاعدتَي DrugBank وKEGG بمعدّل أعلى بكثير من غير المصنَّفة
  (اتجاه p = 1.8 × 10⁻¹⁸ في DrugBank).
- **٧٠٪ من الأزواج بلا درجة سريرية** (`Unknown`). هذا يعني غياب التصنيف في
  المصدر، **ولا يعني أن الزوج آمن**.

## محتويات المستودع

| المسار | المحتوى |
| --- | --- |
| `data/` | ١٧ جدول CSV مع قاموس بيانات تفصيلي (`DATA_DICTIONARY.md`) |
| `docs/index.html` | متصفّح تفاعلي مكتفٍ ذاتياً — بلا أي اتصال بالشبكة، يعمل دون إنترنت |
| `figures/` | جميع الأشكال بصيغتَي PNG وSVG مع شرح كل شكل في `FIGURES.md` |
| `scripts/make_figures.py` | يعيد توليد كل الأشكال من ملفات البيانات مباشرة |
| `examples/quickstart.py` | ستة أمثلة عملية جاهزة للتشغيل |
| `validate.py` | يعيد اشتقاق كل الأرقام الموثَّقة (١٧٧ رقماً) من البيانات نفسها |
| `CHECKSUMS.sha256` | بصمات SHA-256 لكل ملف |

## التحقّق من سلامة السجل

```bash
sha256sum -c CHECKSUMS.sha256   # سلامة الملفات
python3 validate.py             # إعادة اشتقاق كل رقم موثَّق من البيانات
```

## تنبيهات مهمة قبل إعادة الاستخدام

- **`Unknown` لا تعني عدم وجود تداخل**، بل تعني أن DDInter لم يسجّل درجة خطورة
  لهذا الزوج. اعتبارها فئة سلبية سيؤدي إلى تحيّز في أي نموذج.
- **بعض النتائج تستند إلى أعداد صغيرة.** نتيجة SLCO1B1 مبنية على ١٢ زوجاً فقط،
  وفترة الثقة واسعة (1.65–16.64). ستة من الإنزيمات التسعة لم تجتز تصحيح FDR
  وتُعدّ نتائج سالبة.
- **بصمات الإنزيم–العَرَض وصفية لا سببية**، وهي متوسَّطة بفئة الدواء.
- **بعض أسماء الأدوية أسماء تجارية** (`Arthrotec`, `Anzemet`, `Respules`)،
  و`Arthrotec` مستحضر مركّب — استخدم المعرّفات لا الأسماء عند الربط.
- **هذا مورد بحثي وليس أداة دعم قرار سريري**، ولا يصحّ الاعتماد عليه وحده في
  قرارات وصف الأدوية.
