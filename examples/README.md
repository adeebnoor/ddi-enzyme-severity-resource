# Worked usage examples

Run `python3 examples/quickstart.py` after authorised local severity reconstruction. Requires pandas. Recipes show filtering an annotated CYP2C9 subset, summarising long-format occurrence counts by accession-backed human gene, finding drug partners, selecting source-label single-enzyme pairs, joining identifier-only DrugBank accessions, and handling Unknown/NotFound as missing labels. Occurrence profiles do not count unique pairs unless explicitly deduplicated. Graded rows still require source-provenance and benchmark exclusions before supervised use; no clinical decision or externally verified pair filter is claimed.
